# Monthly spending report format

Write the report with these four headings, in this order.

## Summary

One line: the month, the total spent in USD, and the number of transactions.

## Top categories

The three largest categories, largest first, one line each: the category and
its total in USD.

## Chart

A bar chart of the month's spending by category, saved as a PNG file. Title
it "<Month> <Year> spending by category".

## One saving tip

One tip drawn from this customer's own transactions that month. Name the
merchant or category, and how much the customer would have saved.
